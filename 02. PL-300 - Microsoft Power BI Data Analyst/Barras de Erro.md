
## O que são?

Barras de erro mostram a **variação ou incerteza dos valores em um gráfico**.

Elas adicionam uma faixa:

```
Valor médio
     |
     |
  ───────
     |
```

---

Exemplo:

Temperatura média:

|Mês|Temperatura|
|---|---|
|Jan|25°C|

Com barra de erro:

```
25°C
│
20°C ───── 30°C
```

Mostra intervalo.

---

## Usos:

- estatística;
- previsão;
- comparação de variação.

---

## No Power BI

Normalmente aplicadas em:

- gráficos de linha;
- gráficos de dispersão;
- gráficos de colunas.
