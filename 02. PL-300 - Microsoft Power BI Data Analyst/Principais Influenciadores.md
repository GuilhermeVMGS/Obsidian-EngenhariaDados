O visual:

**Principais Influenciadores (Key Influencers)**

responde:

> "O que influencia um resultado?"

Exemplo:

Por que clientes cancelam?

---

Ele possui abas:

---

# 1. Principais influenciadores

Mostra fatores que mais influenciam.

Exemplo:

```
Cancelamento aumenta quando:

+ Cliente sem compra há 90 dias
+ Plano básico
+ Região X
```

---

# 2. Segmentos principais

Agrupa padrões encontrados.

Exemplo:

```
Grupo 1:
Clientes jovens
Alta chance de cancelar

Grupo 2:
Clientes antigos
Baixa chance
```
