
Função automatizada do Serviço do Power BI para descobrir padrões nos dados sem a necessidade de criar visuais manualmente.

- **Funcionamento:** O Power BI executa algoritmos de machine learning sobre o modelo semântico.

- **O que ele busca:**
    - Outliers (valores fora do padrão).
    - Mudanças de tendência em séries temporais.
    - Correlações estatísticas entre duas variáveis.
    - Sazonalidades.

- **Utilização:** A partir dos cartões gerados pelos insights, é possível fixar (pin) os gráficos diretamente em um Dashboard (Painel).
