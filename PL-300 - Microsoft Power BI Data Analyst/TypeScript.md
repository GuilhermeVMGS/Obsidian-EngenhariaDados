
## O que é?

TypeScript é uma linguagem de programação criada pela Microsoft.

Ela é baseada em JavaScript, mas adiciona:

- tipagem estática;
- melhor organização;
- segurança no código.

---

Exemplo JavaScript:

```
let idade = 30;
```

TypeScript:

```
let idade: number = 30;
```
