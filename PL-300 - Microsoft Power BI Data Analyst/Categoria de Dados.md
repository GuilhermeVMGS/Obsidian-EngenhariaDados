
- **O que é:** Uma propriedade aplicada a colunas de texto para instruir o Power BI sobre como interpretá-las no contexto geográfico ou web.

- **Exemplos:** Cidade, Estado, País, Código Postal, URL da Imagem, URL do Web site.
   
- **Foco na prova:**
   - **Geografia:** Permite que mapas localizem os dados corretamente sem ambiguidade (ex.: diferenciar a cidade "Rio de Janeiro" do estado "Rio de Janeiro").

   - **URL da Imagem:** Permite exibir imagens dinâmicas em tabelas em vez do texto do link.
