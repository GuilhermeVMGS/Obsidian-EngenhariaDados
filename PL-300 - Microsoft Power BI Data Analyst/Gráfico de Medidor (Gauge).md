O **Medidor** mostra progresso em relação a uma meta.

Exemplo:

Meta:

```
R$ 100.000
```

Atual:

```
R$ 75.000
```

Visual:

```
0 ----------- 100%

        ▲
       75%
```

---

Ele possui:

## Valor

O que foi realizado.

Ex:

```
Vendas Totais
```

---

## Valor mínimo

Onde começa.

Normalmente:

```
0
```

---

## Valor máximo

Limite.

Ex:

```
100000
```

---

## Meta

Objetivo.

Ex:

```
80000
```

---

Exemplo:

|Campo|Valor|
|---|---|
|Valor|70.000|
|Meta|100.000|
|Máximo|120.000|

Mostra:

70% da meta.

---

## Diferença para KPI

### Gauge

Mostra:

> Quanto falta para chegar na meta?

### KPI

Mostra:

> Estou acima ou abaixo da meta + tendência ao longo do tempo.
