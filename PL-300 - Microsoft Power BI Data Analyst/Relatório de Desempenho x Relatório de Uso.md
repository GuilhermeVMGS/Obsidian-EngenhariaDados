
No Power BI existe o **Relatório de Métricas de Uso**.

Ele mostra como os relatórios estão sendo utilizados.

Possui duas áreas importantes:

---

# Relatório de Desempenho (Performance)

Responde:

> "O relatório está rápido ou lento?"

Mostra informações como:

- tempo de carregamento;
- duração das consultas;
- desempenho dos visuais.

Exemplo:

```
Visual A:
3 segundos

Visual B:
10 segundos
```

Ajuda a encontrar gargalos.

---

# Relatório de Uso (Usage)

Responde:

> "Quem está usando o relatório?"

Mostra:

- quantidade de visualizações;
- usuários;
- frequência;
- tendências de acesso.

Exemplo:

```
Usuários no mês:
250

Visualizações:
1200
```
