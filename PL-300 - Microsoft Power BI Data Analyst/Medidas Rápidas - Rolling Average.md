
Medidas rápidas são medidas DAX criadas automaticamente pelo Power BI.

Você escolhe:

```
Nova Medida Rápida

↓

Rolling Average
```

e ele gera o DAX.

---

## Rolling Average

É uma média móvel.

Exemplo:

Vendas

```
Janeiro   100
Fevereiro 120
Março     140
Abril     200
```

Média móvel de 3 meses

Abril

```
(120+140+200)/3
```

Não considera apenas Abril.

Considera uma janela de tempo.

---

Quando usar?

- tendências
- sazonalidade
- reduzir oscilações
