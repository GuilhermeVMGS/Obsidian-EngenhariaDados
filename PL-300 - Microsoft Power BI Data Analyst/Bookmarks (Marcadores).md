
Marcadores servem para salvar o **estado** do relatório.

Estado significa tudo que está acontecendo naquele momento.

Exemplo:

```
Ano = 2025

Estado = MG

Produto = Notebook

Página = 2
```

Você quer voltar exatamente para isso depois.

---

## Adicionar

Cria um novo marcador.

É como tirar uma fotografia.

```
📸

Estado salvo.
```

---

## Atualizar

Você já possui uma fotografia.

Mudou filtros.

Quer substituir.

Então:

Atualizar.
