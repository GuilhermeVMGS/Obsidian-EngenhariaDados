
Para entender o "motor" por trás disso (especialmente na biblioteca **Pandas** do Python), imagine o seguinte:

- **Séries (Series):** Um DataFrame é, na verdade, um conjunto de colunas grudadas. Cada coluna individual é chamada de _Series_.
- **Índices:** Além dos dados, o DataFrame possui um **Index** (rótulos para as linhas) e **Columns** (rótulos para as colunas). Isso permite que você acesse dados pelo nome, em vez de apenas pela posição numérica.
- **Alocação de Memória:** Internamente, os dados são armazenados de forma otimizada para que operações em colunas inteiras sejam extremamente rápidas (processamento vetorial).
