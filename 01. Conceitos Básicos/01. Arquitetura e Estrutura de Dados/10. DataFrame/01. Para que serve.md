Ele serve para:

- **Limpeza de Dados:** Remover valores nulos ou corrigir erros.
- **Transformação:** Criar novas colunas baseadas em cálculos de outras.
- **Agregação:** Somar, tirar médias ou agrupar dados (tipo uma Tabela Dinâmica).
- **Integração:** Ler dados de arquivos CSV, Excel, bancos de dados SQL ou JSON e transformá-los em algo manipulável via código.
